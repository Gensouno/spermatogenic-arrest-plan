# 当前方法与解释边界

## 研究问题与单位

本项目先描述八个全睾丸队列的 KO−WT 表达效应是否相似，再检验组成参考模型能解释哪些表达模式、在哪里失败。没有预设所有模型一定共享一个机制。

56 个主分析样本、七种遗传扰动；Rfx2 两年龄队列来自同一研究。样本是各队列内差异分析的重复；基因、两模型组成的“模型对”、同一图谱的来源批次都不自动成为独立生物重复。年龄、遗传扰动和平台混杂，不能由本设计单独分离。

## 导入与各队列效应估计

所有基线效应方向固定为 KO−WT。各队列独立处理，不合并原始表达矩阵，也不对全数据先做跨平台批次校正。

| 类型 | 当前流程 | 关键限制 |
|---|---|---|
| XAP5、N6amt1、两 Rfx2 的基因 counts | 检查样本列与整数非负值；Ensembl gene ID 用 org.Mm.eg.db 单值映射；同 symbol 求和；filterByExpr、TMM、voom、limma | 注释版本可改变映射；两个 Rfx2 各有 1,989 个未映射或歧义 ID 被排除 |
| Hnrnpgt 旧转录本特征 counts | 排除 5 条 HTSeq 汇总行；固定 GRCm38 Ensembl 79 transcript→symbol；同 symbol 求和，再用 TMM/voom/limma | 原始 GTF 版本未明确；保留计数质量高不等于已证明原始特征定义完全正确 |
| Rnu11 TPM | 至少三样本 TPM≥1；log2(TPM+0.5)，limma-trend，robust=TRUE | 不是原始 counts，不执行 voom 或 counts 组成拟合；不是原文 IsoDE2 的精确复现 |
| Sin3a Agilent | 单 Cy3 通道；normexp offset=50；quantile；去控制探针；唯一 symbol 映射；同基因平均 log2 探针表达 | 不是旧方案所称的双通道 loess；每组仅两例 |
| Dazap1 Affymetrix | 验证 mouse4302；RMA；mouse4302.db 单值映射；同基因平均 log2 probeset 表达 | 与原研究 MAS5 处理并不完全相同 |

芯片基因层效应用 limma-trend robust 估计。各表均保留全部受检基因；描述性 DEG 计数采用队列内 BH 调整 P<0.05 且 |logFC|>1，不将未调整 P 值当 FDR 证据，也不以 DEG 数量比较哪个模型“更严重”。

官方证据表保留 GSM、原始标题、source、characteristics 和赋予的组别。代码自动核对标题与样本 ID，Hnrnpgt 另核对 genotype；其他分组仍依赖对来源特征的核查解释。未确认的 N6amt1 年龄及早期推断的阻滞节点不用于分期因果分析。

## 跨模型比较与敏感性

主图以八队列共同受检的 8,099 个基因为固定交集，计算基因层面 logFC 的 Spearman 相关。另保存每对队列各自共有基因的相关及基因数；两类结果的基因集合不同，不能混用数字。没有先按显著性选择“共同基因”来制造相关。不同单位、平台与标准化仍会影响效应，相关是描述性结果，不提供假定基因独立的极小 P 值。

63 个变体包括：56 次逐样本删除、三个 TPM 伪计数（0.1、1、2；基线 0.5）、两个芯片各两种探针汇总方式（中位数、按全样本平均强度选代表探针）。没有按组间差异挑探针。

counts 留一重算过滤、TMM、voom；TPM 留一重算丰度过滤和模型。芯片留一固定全样本标准化后的探针矩阵，因此只检验条件效应估计的敏感性，不是每轮重新 RMA/quantile 的完整预处理验证。P0 队列删一后某组 n=1，只作压力诊断。一次仅变动一研究，另一研究保持基线；范围不是置信区间，也不是所有参数同时变动的穷举范围。没有据敏感性结果剔除样本。

## 组成参考与审计

图谱 [Green et al. 2018](https://pubmed.ncbi.nlm.nih.gov/30146481/) 的原始 DGE 逐基因流式聚合，避免构造约十 GB 的稠密细胞矩阵。排除 2,205 个 Unknown，保留 25 个来源批次，将已知细胞合并为 Somatic、Spermatogonia、Meiotic、Postmeiotic。来源批次未证实为独立动物，不能称为留一动物验证。

1. 同参考谱生成 200 个 Dirichlet RNA 混合物，比较 log 空间 NNLS 与线性 CPM NNLS。这个实验只检查代数假设，不属于独立生物验证。默认审计使用从冻结原始图谱重建的 pooled 谱，不再依赖未入库的旧舍入参考文件。
2. 对每类至少 20 个细胞的 15 个来源批次留一，使用其余批次拟合，测试每批次 100 个合成混合物。比较全基因、加权全基因、训练参考内选标记的三种方法。方法比较本身是探索性，不把选择加权方法后的同一实验当最终验证。
3. 保存全批次 pooled 与官方明确未富集的 ST1–6-only 两参考。ST7/ST8 与官方标题的别名尚未解决，不猜测映射。
4. 五个 counts 队列作五折基因留出预测，比较观察到的 log2(组均值 CPM+0.5) KO−WT 与参考模型预测。此观察量不是 limma logFC；CPM 库大小来自完整样本，基因相关性也仍存在。它不是留出动物或跨研究外部预测。

系数经非负拟合后归一化，称为“拟合 RNA 权重”，不作为已验证的 RNA 真值或细胞数比例。RNA 含量、基因长度、UMI 与 bulk 读数技术差异、年龄和状态失配均可能使权重偏差。线性混合假设不允许直接在 log(S+1) 上把系数当线性组织比例。

将观察效应写作 O=P+R 时，跨队列协方差包含四项：预测协方差、残差协方差，以及两个交叉协方差。代码检查四项之和等于总协方差；不把某项除以总协方差称为因果百分比。不执行旧规格中的 compShare/MRM 机制结论，也不将置换零分布区间称为置信区间。

## 外部兼容性及细分失败检查

使用 [da Cruz et al. 2016](https://link.springer.com/article/10.1186/s12864-016-2618-1) 补充表的独立分选标签。2C 是混合群，不当纯精原细胞；LZ 和 PS 都属于减数分裂但阶段不同，RS 为圆形精子细胞。七个含歧义数字字符串的基因记录后排除，不猜测数值；涉及 Prm1/Prm2/Sycp3 等标记，因此排除本身可能影响结果。RPKM 与参考在共有基因内缩放，所得仅是表达谱兼容性诊断，不是完整已知比例混合物恢复。

另读取作者的 12 生殖群 Average/Total 表，利用逐群细胞数验证自然对数恒等式；exp(Average)−1 完整列和为 10,000。27 行日期化基因名记录后排除，不能按日期猜测还原。比较同表按原始细胞数加权合并的四类参考，与 12 生殖群加同一个体细胞谱的 13 成分参考，固定基因、拟合权重及五折划分。该细分尝试由同一外部资料的失败推动，属于探索性修订，不再是未被查看过的最终验证。

两种分辨率都未可靠恢复 LZ 身份；不把更多参数或个别误差减小当作比例准确性成立。技术、年龄、标记排除与分期覆盖的影响尚未分离，需要新的独立标签和重复资料进一步验证。
