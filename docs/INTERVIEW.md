# 面试讲解提纲：先理解，再使用

这是一份练习提纲，不是要求背诵的个人经历。只讲自己能解释、能打开代码和结果核查的部分；公开数据来自原作者，代码有 AI 辅助，不声称独立开展了动物或测序实验。

## 三分钟讲清楚

**问题。** 不同基因扰动都会造成生精障碍，但全睾丸是混合组织。类似的表达变化，可能来自相似细胞内反应，也可能只是发育阶段或细胞组成变化。我想先分清观察到什么，再讨论解释。

**数据和实现。** 整理了八个队列、56 个主分析样本，涉及七种遗传扰动。它们既有 counts，也有 TPM 和芯片。我把每个队列单独分析，只在基因效应层面比较，并核查样本来源、计量单位、旧基因 ID 和参考谱。Rfx2 的两个年龄不是独立遗传模型。

**结果。** 部分模型的效应关联在样本和参数敏感性中保持方向，也有模型反向或接近不相关。因此不能简单说“所有生精阻滞都共享同一个表达反应”。组成拟合能再现一些模式，但独立分选资料揭示早期减数分裂失配，细分参考仍不足以解决。

**收获和边界。** 项目最重要的收获不是一个漂亮的百分比，而是学会检验参考与统计假设。我保留失败检查、完整来源和重跑入口。现阶段不宣称可靠的细胞比例、组成因果贡献或共同机制；下一步需要年龄适配且带独立标签和重复的资料。

## 常见追问

**为什么不直接取共同差异基因交集？** 交集受样本量、检测基因集合、平台和显著性阈值影响；共同下调也可能只反映晚期细胞减少。先比较完整共同受检基因的效应，再解释组成假设，避免把列表交集当机制证明。

**为什么 TPM 不和 counts 一起跑？** TPM 是归一化相对丰度，不是原始测序计数。当前只用 log TPM 的单独敏感性模型，不把它输入 counts 的 TMM/voom 或组成分支。

**高 R² 为什么不证明比例准？** 不同错误系数可能给出相近表达重建；log 空间还破坏了原始混合的线性关系。已知混合物中的权重误差和外部标签诊断都比只看重建分数更有针对性。

**RNA 权重与细胞数有何区别？** 一个细胞的 RNA 含量并不等于另一个细胞，测量技术也有偏差。即使 RNA 贡献拟合得好，也不能直接换成细胞数；本项目的拟合 RNA 权重本身也没有被当作真实 RNA 比例认证。

**负结果意味着项目失败吗？** 它否定了一部分过强解释，并保留了可复现的表达比较。不能把失败包装成新机制，也不必为了得到预期答案删样本或调参到“通过”。

**你具体做了什么，AI 做了什么？** 如实说明自己提出的问题、核查和理解的步骤、能解释的代码与图，以及 AI 辅助生成或修改的部分。遇到尚未理解的实现先回代码验证，不声称全部独立完成。
